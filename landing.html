Parcel to report

What an Argus screen does.

A parcel boundary goes in. The result is a geospatial screening record for your team to inspect.

01

Load the boundary

Upload GeoJSON in the workspace or pass a parcel file to the CLI. Multi-feature GeoJSON can be handled as a portfolio.

GeoJSONParcel IDGeometry validation
02

Select and compare scenes

Search STAC for Sentinel-2 imagery in the reference and current periods. Argus compares red and near-infrared bands over the parcel and calculates NDVI change.

Cloud cover filterNDVISentinel-1 visual comparison
03

Review the output

Inspect the change map, scene details and parcel metrics. Export a comparison PNG, a PDF report or machine-readable JSON.

Canopy loss areaScene datesPDF · JSON · PNG

Run Argus

A CLI for audits. An API for your workflow.

Start with one parcel from the command line. Use the service API and batch endpoint when the screening needs to sit inside an existing sourcing or risk process.

  • ✓Use familiar geospatial files: GeoJSON, Shapefile and other GDAL-readable formats.
  • ✓Run on CPU or CUDA: GPU acceleration is optional.
  • ✓Pass on the result: use JSON and API responses in your own procurement or ERP integration.
Cloud audit · CLIEXAMPLE COMMAND
$ ./bin/argus audit farm_parcel.geojson \
    --save-png audit_map.png \
    --pdf audit_report.pdf \
    --json
Report fields
asset_id · parcel_area_ha · deforested_ha
canopy_loss_percent · mean_delta_ndvi · verdict

Imagery availability, cloud cover and parcel geometry affect the result. The report records a screening run for review.

Where the satellite screen fits

Forest-change screening is one part of due diligence.

Argus examines vegetation change on a supplied plot. Use that result alongside supplier records, production-legality evidence and your wider risk assessment.

The operator makes the due-diligence assessment

Argus provides geospatial screening evidence. The operator remains responsible for the full due-diligence process, risk mitigation and any statement submitted under EUDR.
